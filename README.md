# Still

Галерея для Android от автора браузера [Plume](https://github.com/eagalts/Plume).

- **Один экран.** Только лента; поиск, альбомы и действия открываются поверх неё. Единственная кнопка — знак внизу.
- **Твои фото отдельно от шума.** Снятое камерой живёт в ленте всегда; скриншоты, мессенджеры и загрузки через 14 дней сами тихо уходят в «Поток». Серии и дубли складываются в стопки.
- **Всё на телефоне.** Без сети, облака, аккаунтов, аналитики и рекламы. Свой индекс — только зашифрованным; «Поделиться» по умолчанию без места съёмки.

## Сборка

JDK 17+, Android SDK 35.

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

Ключ подписи в репозитории не хранится: `still.storeFile`, `still.storePassword`, `still.keyAlias`, `still.keyPassword` — в `~/.gradle/gradle.properties`.
